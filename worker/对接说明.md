# 讯飞语音评测 · 对接说明

## 一次性的三件事

| 步骤 | 谁做 | 耗时 |
|---|---|---|
| 1. 注册讯飞 + 实名 + 创建应用 | **你** | 10 分钟 |
| 2. 双击 `一键部署.bat`，粘贴三个密钥 | **你** | 3 分钟 |
| 3. 把生成的地址填进 App 设置 | **你** | 30 秒 |

代码部分（Worker 代理、音频采集、评分解析）**已经写完**，不用你改。

---

## 第 1 步：拿讯飞的三个密钥

1. 打开 https://www.xfyun.cn/ 注册
2. 实名认证（身份证 + 手机号，个人即可）
3. 控制台 → **创建应用**（名字随便）
4. 在该应用里 **添加服务** → 选 **「语音评测（流式版）」**
5. 回到应用 → **服务接口认证信息**，抄下：

```
APPID       （5~8 位）
APIKey      （32 位）
APISecret   （32 位）
```

> 免费额度：**创建应用后每天 500 次**，个人练习够用。
> 如果额度用完，可以购买套餐，或第二天恢复。

---

## 第 2 步：双击部署

```
worker\一键部署.bat
```

脚本会依次做：

1. 检查 Node.js
2. 安装 wrangler
3. 让你输入三个密钥
4. 打开浏览器登录 Cloudflare（邮箱注册，免费，不需要信用卡）
5. 把密钥写入 Cloudflare（**不会出现在网页代码里**）
6. 部署，打印地址并**自动复制到剪贴板**

成功后会显示：

```
✅ 部署成功！
把这个地址填进 App：
  设置 → 语音评测服务地址

  wss://ise-proxy.你的子域.workers.dev/ise
```

## 工作原理

```
浏览器                          Cloudflare Worker              讯飞 ISE
──────                          ─────────────────              ────────
麦克风 → 16kHz PCM
   │
   └── WebSocket ───────────▶  算 HMAC-SHA256 签名
                               （APISecret 只在这）
                                     │
                                     └── 建立上游 WS ──────▶  wss://ise-api.xfyun.cn
                                     ◀── 评分 XML ─────────
   ◀──────────── 原样回传 ───────────┘
解析 XML → 总分/准确/流畅/完整/逐词分数
```

- 密钥只在 Cloudflare，**前端拿不到**
- 音频不落地，用完即弃
- 免费额度：Worker 10 万次/天，讯飞 500 次/天

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 提示「未配置评测服务地址」 | 还没填地址 | 设置里填 wss 地址 |
| 提示「连接评测服务失败」 | Worker 没部署成功 / 地址写错 | 地址必须以 `wss://` 开头，结尾带 `/ise` |
| 提示「讯飞返回错误」 | 密钥错、额度用完、IP 白名单 | 控制台检查；关闭 IP 白名单 |
| 一直「正在听…」 | 麦克风没弹出授权 | 检查浏览器麦克风权限 |
| 分数很低但自我感觉良好 | 麦克风离太远 / 环境吵 | 靠近麦克风，安静环境重试 |
